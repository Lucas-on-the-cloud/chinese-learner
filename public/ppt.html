05 · Concept Deep Dive
🦴

HTML

The bones of every webpage

HTML (HyperText Markup Language) is how you tell the browser what's on the page — headings, paragraphs, images, buttons, links.

Think of it as the skeleton of a person. Without it, there's nothing to dress up.
<!-- a heading and a paragraph -->
<h1>Hello, world</h1>
<p>This is my first website.</p>

How you'll use it

  • 1
    Open VS Code and create a file ending in .html
  • 2
    Use tags like <h1>, <p>, <img> to add content
  • 3
    Open it in your browser — boom, a webpage
  • 4
    Or just ask Claude: "add a section with my bio and a photo"
06 / 16
06 · Concept Deep Dive
👗

CSS

The clothes, the makeup, the vibe

CSS (Cascading Style Sheets) is how you tell the browser what things should look like — colors, fonts, spacing, layout, animation.

If HTML is your skeleton, CSS is your outfit, hairstyle, and how you walk into the room.
/* make the heading orange and big */
h1 {
  color: coral;
  font-size: 48px;
}

How you'll use it

  • 1
    Write CSS in a .css file (or inside a <style> tag)
  • 2
    Pick an HTML element, then describe its look
  • 3
    Change one number, refresh — instant feedback
  • 4
    Or ask Claude: "make the homepage warm and minimalist, soft beige background"

07 · Concept Deep Dive
🧠

JavaScript

The brain that makes things move

JavaScript is how your website reacts — when someone clicks a button, types in a form, or scrolls down, JS decides what happens next.

HTML stands there. CSS looks pretty. JavaScript actually does things.
// when the button is clicked, say hi
button.onclick = () => {
  alert("Hello!");
};

How you'll use it

  • 1
    Add a .js file — or a <script> tag in your HTML
  • 2
    Use it for: dark mode toggle, image carousel, form validation, animations
  • 3
    Don't worry about syntax — Claude writes it
  • 4
    Ask Claude: "add a button that switches between light and dark mode"

08 · Concept Deep Dive
☁️

Git & GitHub

Save points + a home on the internet

Git is a tool that saves snapshots of your project as you work — so you can always undo, compare, or rewind. GitHub is the website where those snapshots live online.

Git = save points in a video game. GitHub = the cloud save so it doesn't die with your laptop.
# the three commands you'll use 90% of the time
git add .
git commit -m "added the about page"
git push

How you'll use it

  • 1
    Sign up at github.com (free, takes 2 min)
  • 2
    Create a repository (a folder for your project)
  • 3
    Commit = save a snapshot · Push = send it to GitHub
  • 4
    Bonus: GitHub Pages turns your repo into a live website — for free

09 · Concept Deep Dive
🗄️

Supabase

Your website's memory

Supabase is a free service that handles the backend for you — the database (where info is stored), user logins, and the connection between them.

Think of it as a magical notebook your website can write to and read from — and it remembers everything, forever.
// save a new student's progress
supabase
  .from("progress")
  .insert({ user: "Lucas", level: 3 });

How you'll use it

  • 1
    Sign up at supabase.com — create a project
  • 2
    Make a table (like an Excel sheet) for your data
  • 3
    Connect it to your site with one API key
  • 4
    Now users can sign in, save things, come back later — like tocflfafa.com does
